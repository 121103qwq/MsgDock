### B-112 Android 页面上下留白和键盘遮挡输入框

- 状态：`FIXED_0.7.6_EMULATOR_AND_HYPEROS_LAYOUT_VERIFIED`
- 原因：SDK 兜底打包把 uses-sdk 追加在 application 之后，导致系统解析应用时采用旧版兼容默认值。界面也缺少统一的系统栏与输入法避让。
- 修复：打包时先声明 SDK；主页面和后台教程统一处理系统栏、挖孔和键盘边距，滚动区域随键盘缩小。
- 验证：Android 14 独立模拟器确认不再 letterbox；全屏、键盘焦点与收起恢复、大字体真实横屏及教程返回通过。59 项 JVM、SDK 构建和 v2/v3 签名通过。测试证据及首轮旋转误判见 HANDOFF。
- 真机补验：2026-10-01，小米 2407FRK8EC / Android 16 / HyperOS OS3.0 无线覆盖升级后，首页、系统栏、普通输入法可视区及教程返回通过。密码键盘截图被系统遮黑，仅有控件范围证据，未关闭保护。
- 边界：v0.7.6 为预览版；其他系统、真机横屏与大字体尚未补验，Gradle lint 未运行。

### B-113 Windows 紧急通知、双重提醒与补齐消息堆积

- 状态：`FIXED_0.7.6_NATIVE_API_VERIFIED`
- 原因：Toast 使用 urgent/long；原生通知成功后仍追加托盘气泡。每条消息独立弹出，历史补齐也触发通知。
- 修复：普通短时静音通知、固定 Tag/Group 替换、10 秒弹窗节流、历史静默。托盘仅在原生失败时兜底，复制成功不再弹气泡；近期明确验证码自动复制。
- 验证：Go 全套测试与 vet 通过；真实 WinRT 属性读取通过，隔离 QA AppID 连续投递 3 条后通知中心只保留 1 张卡片，测试记录已清理。策略测试覆盖连续 20 条、历史/未来消息、失败重试和去重。
- 本机补验：2026-10-01，安装版 v0.7.6 通过实际 localhost 接收 3 条合成消息并持久保存，最后一条验证码自动写入 Windows 剪贴板，随后恢复此前文本。
- 边界：v0.7.6 为预览版；通知按钮点击与真实 SMS 端到端尚未验收，不能把原生 API 成功当成可见横幅或点击成功。

### B-111 未登录时无法查看已保存的 LAN / 配对云端短信

- 状态：`RESOLVED_0.7.4_EMULATOR_VERIFIED`
- 现象与原因：LAN / 配对云端短信已写入 cloud-inbox.jsonl，但历史入口强制登录且只读当前账号记录，通知错过后无法从界面查回。
- 修复：首页本机收件箱复用原账本，未登录读取非账号记录，登录后增加当前账号历史；过滤账号后按共享消息 ID 去重，保留底层记录。详情和复制操作继续检查账号快照。
- 验证：56 项 JVM 测试通过；Android 14 独立 MCP 覆盖升级保留 v0.7.3 历史、真实 LAN HTTP 重发只显示一条、全文/验证码实际粘贴、进程重开、A/B/退出三个本地合成账号状态隔离，共 5 项通过，崩溃日志为空。合成账号测试数据已恢复。
- 边界：未使用真实账号收发、真实 SMS 或厂商系统锁屏，仍按 B-001 单独验收。

### B-110 Android 权限未确认就扫描，接收状态只反映保存开关

- 状态：`EMULATOR_VERIFIED_0.7.3_NEEDS_DEVICE_TEST`
- 触发：首次点击扫描/启动，停留或拒绝系统权限弹窗；或接收服务启动/绑定端口失败。
- 原因：requestPermissions 后未返回且没有结果回调；状态仅看 receiver_enabled；每次扫描创建的 Executor 未关闭，扫描异常也被当成未发现设备。
- 修复：权限回调决定是否继续，通知拒绝仍可接收；使用服务实际启动/监听状态；单次有时限扫描、重复点击保护、销毁取消和明确失败提示。保留短信广播、LAN 协议、账号与旧云端独立循环。
- 验证：53 项 JVM 测试及 Android 14 独立模拟器 11 项检查通过。实际点击拒绝/允许权限、旋转屏幕后继续扫描；故意占用 58123 复现 EADDRINUSE，界面明确显示监听失败，释放后重启恢复；关闭通知时 LAN 鉴权/落盘/重发去重通过，进程终止后显式重开可恢复已启用服务和原历史。崩溃日志为空。
- 边界：尚未连接真实手机；真实 SMS、锁屏、系统重启与后台保活仍按 B-001 单独记录，不能用模拟器结果代替。

### B-108 手机浏览器注册报 cors_forbidden

- 状态：`RESOLVED_2026_09_05`；线上同源注册/Cookie 登录、HTTP 跳转和外部来源拦截已验证。具体同学手机仍需刷新 HTTPS 页面后重试。
- 原因：线上 HTTP 入口也直接提供表单，但 Origin 白名单仅含 HTTPS 主域名；同一 Worker 的 workers.dev 网页入口也不在白名单。修复前已用 HTTP GET 200 和对应 OPTIONS 403 复现。
- 修复：静态资源先过 Worker，HTTP 页面 308 到 HTTPS、HTTP POST 拒绝；HTTPS 精确同源放行，陌生/opaque Origin 仍拒绝；增加中文错误提示。
- 本地验证：13 项 Worker 测试通过，新增 HTTPS 同源注册/Cookie、HTTP 跳转、外部来源拒绝测试。截图未显示完整 URL，不能据此断言同学使用了哪个入口。

### B-107 生产注册返回 500，但本地账号测试通过

- 状态：`RESOLVED_2026_09_05`
- 原因：生产 Web Crypto PBKDF2 最多支持 100,000 次，原代码使用 310,000 次；模拟器未复现此限制。
- 修复：改用支持的 100,000 次并增加服务端用途隔离 HMAC；不引入第三方加密依赖，不降低为快哈希。
- 验证：typecheck、10 项本地测试及 16 项线上 API 测试通过，包括正确/错误密码、设备撤销和用户隔离。
